## 저장소 파일 및 디렉터리 구성

저장소 내 파일들은 날짜별 진도와 난이도 단계별로 체계적으로 분류되어 있습니다.

```text
Workspace/
├── 교육과정.xlsx               # 전체 커리큘럼 일정 및 상세 학습 로드맵
├── YYYYMMDD/                   # 일자별 실습 코드 디렉터리 (예: 20261023)
│   ├── 실습파일/
│   │   ├── 01_기본필수/         # 기본 핵심 파이프라인 및 단위 전처리 실습
│   │   ├── 02_응용/            # 엔드투엔드 파이프라인 및 복합 데이터 처리
│   │   ├── 03_심화/            # 고급 모델링, 튜닝 및 최적화 실습
│   │   ├── README.md           # 해당 일자 세부 가이드
│   │   └── requirements.txt    # 실습에 필요한 패키지 의존성
│   └── test.py                 # 빠른 코드 검증 및 스모크 테스트용 스크립트
└── .gitignore                  # 가상환경(.venv), 캐시 및 임시 파일 제외 설정
```

### 각 디렉터리 및 파일의 성격

1. **`교육과정.xlsx`**
   - 전체 교육의 단계별 모듈, 주차별/일자별 학습 주제, 권장 선수 지식 및 성취 목표를 정리한 커리큘럼 기준 문서입니다.

2. **일자별 폴더 (`YYYYMMDD/`)**
   - 당일 진행된 강의 내용과 직접 구현한 핸즈온 코드가 일자별로 격리 보존됩니다.
   - 복습 시 진도에 맞춰 히스토리를 추적하기 용이하도록 구성되어 있습니다.

3. **`01_기본필수/` (Essential)**
   - 머신러닝/엔지니어링의 기본 뼈대를 이루는 필수 코드군입니다.
   - 결측치 처리(`SimpleImputer`), 범주형 인코딩(`OneHotEncoder`), 스케일링(`StandardScaler`), 통합 전처리(`ColumnTransformer`, `Pipeline`) 등 데이터 누수(Data Leakage)를 방지하는 표준 구현체를 포함합니다.

4. **`02_응용/` (Applied)**
   - 기본 단계를 넘어 실제 데이터셋을 결합하고, 다차원 피처 엔지니어링 및 결합 모델을 검증하는 중간 난이도의 실무 예제입니다.

5. **`03_심화/` (Advanced)**
   - 하이퍼파라미터 탐색, 모델 앙상블, 예측 추론 최적화 등 성능 극대화와 심층 분석을 다루는 코드입니다.

6. **`requirements.txt`**
   - 각 실습 환경을 로컬 PC에서 충돌 없이 재현할 수 있도록 필수 라이브러리 및 호환 버전을 명시해 둔 의존성 파일입니다.
