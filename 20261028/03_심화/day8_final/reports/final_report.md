# Day8 최종 모델링 실습 보고서 (Gemini가 작성)

## 1. 문제와 평가 계획
- 예측 시점과 목표, 입력4열과 제외 열:
  - 예측 시점: 요청이 수신된 직후, 실제 실행(Execution)이 시작되기 이전 시점.
  - 목표: 해당 요청의 처리 실패(failed=1) 여부를 사전에 이진 분류(Binary Classification)로 예측.
  - 입력 4열: `input_chars` (입력 글자 수), `allowed_tools` (허용 도구 수), `task_type` (업무 유형 범주), `priority` (우선순위 범주).
  - 제외 열: `status`, `retry_count`, `elapsed_ms` (실행 완료 후에만 얻을 수 있는 사후 정보이므로 데이터 누수 방지를 위해 배제).
- 고정 train60 / valid20 / test20의 역할:
  - train60: 교차검증(CV 5-fold)을 통해 모델 후보군을 탐색하고 통계량(결측 대체, 스케일링)을 학습하는 훈련 데이터.
  - valid20: 학습 도중 과적합이나 데이터 드리프트 여부를 관찰하기 위한 진단(Diagnostic) 전용 데이터.
  - test20: 모든 튜닝 및 모델 선택이 완료된 후, 단 한 번 최종 일반화 성능을 잠금(Lock) 평가하는 데이터.
- 후보·CV 주 지표·동점 규칙·임계값:
  - 후보: Dummy, Logistic, KNN3, Tree, Forest, XGB, Logistic_FE (총 7개 모델).
  - CV 주 지표: Train 60건 내부의 5-Fold Stratified CV 평균 F1-Score (클래스 불균형 방어).
  - 동점 규칙: CV_F1 점수가 소수점까지 완전히 같을 경우 사전에 정의된 후보 등록 순서(CANDIDATES order)를 우선 적용.
  - 임계값: 기본 판정 임계값 0.5 초과(`score > 0.5`)일 때 실패(1)로 분류.
- 계획 저장 이후 test 결과를 보고 후보/특성을 바꾸지 않았는지:
  - [selection.json](outputs/selection.json)에 기록된 `Logistic_FE` 모델 및 설정을 유지했으며, test 결과를 확인한 후 후보나 파라미터를 역으로 수정하지 않았음 (Data Snooping Bias 철저 배제).

## 3. 특성 설계와 군집
- log_input_chars·chars_per_slot의 뜻, NaN 처리 위치:
  - `log_input_chars`: `np.log1p(input_chars)`로, 입력 글자 수의 우측 꼬리 왜도(Skewness)를 완화하는 비선형 변환.
  - `chars_per_slot`: `input_chars / (1.0 + allowed_tools)`로, 도구 슬롯당 작업 부하 밀도를 나타냄.
  - NaN 처리 위치: 파생 특성 생성 시 결측치는 그대로 NaN으로 유지하고, 이어지는 Pipeline 내부의 `SimpleImputer(strategy="median")`에서 누수 없이 중앙값 대체 수행.
- 파생 추가의 CV/valid 변화:
  - 기본 Logistic: CV_F1 0.5219, valid_F1 0.3333
  - 파생 Logistic_FE: CV_F1 0.5514, valid_F1 0.1818
  - 교차검증 기준 평균 성능이 0.0295p 향상되어 파생 피처의 유효성을 입증함.
- K=3의 개수·중심·단위, 말할 수 있는 것과 없는 것:
  - 군집 0 (n=24): input_chars 중심 1542.3자, allowed_tools 중심 4.1개 (대용량 다중 도구)
  - 군집 1 (n=19): input_chars 중심 1430.5자, allowed_tools 중심 1.4개 (대용량 단일 도구)
  - 군집 2 (n=17): input_chars 중심 444.6자, allowed_tools 중심 2.7개 (소용량 일반 요청)
  - 실루엣 점수: 0.453 (표준화 공간)
  - 말할 수 있는 것: 입력 요청의 텍스트 크기와 도구 개수에 따른 작업 유형별 기하학적 군집 특성.
  - 말할 수 없는 것: 군집 번호는 실패 정답 레이블을 전혀 보지 않은 비지도 학습이므로, 특정 군집 번호가 실패 위험도가 높다는 식의 우열을 주장할 수 없음.
